# Modern Investment Analytics Platform

An end-to-end financial analytics platform designed to demonstrate modern data engineering and analytics engineering practices. The platform ingests market data, company fundamentals, and economic indicators through automated Python ETL pipelines, stores analytical data in DuckDB, transforms raw data into business-ready models using dbt, and delivers investment insights through interactive dashboards.

The project follows production-style data engineering principles, including automated workflows, dimensional modeling, data validation, testing, and reproducible pipeline execution.

## Technology Stack

* **Data Ingestion:** Python, REST APIs
* **Data Warehouse:** DuckDB
* **Transformations:** dbt, SQL
* **Workflow Automation:** GitHub Actions
* **Visualization:** Power BI
* **Development Practices:** Git, CI/CD, automated testing
